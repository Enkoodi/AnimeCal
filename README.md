# 番剧日历 (AnimeCal)

一个很小的 Windows 桌面悬浮日历，用来盯你正在追的番剧更新日。  
窗口大小接近系统日历，可置顶、收起成迷你条，关掉会进托盘而不是退出。

---

## 发给别人用，对方要装什么？

**一般不需要安装 Node、Rust 或其它开发工具。**  
对方拿到 `anime-cal.exe`（或安装包）后，直接双击即可。

| 系统 | 通常情况 |
|------|----------|
| **Windows 11** | 自带运行组件，**多数情况什么都不用装** |
| **Windows 10** | 若打不开或白屏，需安装 **Microsoft Edge WebView2**（见下） |
| Windows 7 / 8 | 不支持 |

### 唯一可能要装的：WebView2

本应用基于桌面壳（Tauri），界面依赖微软的 **WebView2** 运行时。

- 说明与下载页（官网）：  
  [https://developer.microsoft.com/microsoft-edge/webview2/](https://developer.microsoft.com/microsoft-edge/webview2/)
- 推荐安装「常青版引导程序 / Evergreen Bootstrapper」：  
  [https://go.microsoft.com/fwlink/p/?LinkId=2124703](https://go.microsoft.com/fwlink/p/?LinkId=2124703)

装好后重新打开 `anime-cal.exe` 即可。

> 若你发放的是带安装向导的 NSIS 安装包，且打包时启用了 WebView2 引导，安装过程中也可能自动提示安装；直接拷贝绿色 exe 时，请按上面链接自行安装。

### 网络

从 Bangumi 添加番剧时，需要能访问：

- [https://bgm.tv](https://bgm.tv)（番组计划）
- [https://api.bgm.tv](https://api.bgm.tv)（公开 API）

纯手动添加番剧时，不强制依赖外网。

## 怎么运行

1. 拿到 `anime-cal.exe`
2. 双击打开  
3. 若被 Windows 智能筛查拦截：选「仍要运行 / 更多信息」即可（未签名的个人软件常见提示）

关闭窗口右上角 ×：**隐藏到托盘**，不会真正退出。  
要退出：托盘图标右键 → **退出**。

---

## 功能简介

- **日历**：有更新的日期显示绿点和数量
- **点某一天**：查看当天关注番剧（封面、时间、集数）
- **点某部番剧**：可手动改这一天播的是第几集（支持一天连播多集）
- **添加番剧**：打开独立管理窗口，从 Bangumi 搜索 / 筛当季，或手动填写
- **再点已添加**：可取消关注
- **置顶 / 收起 / 托盘**：适合挂在桌面角落

换季后（如 9 月、10 月新番），重新打开「管理番剧」或点「刷新列表」，会拉取 Bangumi 当前放送表。

---

## 使用步骤（第一次）

1. 打开应用 → 底部 **设置（齿轮）** → **管理番剧**  
   （或在某日详情里点「添加番剧」）
2. 在弹出的大窗口里选 **从 Bangumi 添加**
3. 用星期 / 评分 / 名称筛一下，点你在追的番剧（出现 ✓）
4. 关掉管理窗口，回到日历查看更新标记

手动添加时请填写 **首播日期**（和可选总集数），否则无法正确计算播出区间。

## 日常操作

| 操作 | 说明 |
|------|------|
| 点日期 | 进入当天番剧列表 |
| 在列表里再点某部番 | 调整本日起始集 / 连播集数 |
| 左右箭头 | 换月份；双击月份标题回到本月 |
| 图钉 | 窗口置顶开/关 |
| 收起 | 变成迷你条（可拖动）；点展开或双击恢复 |
| × / － | 藏到系统托盘 |
| 托盘左键 | 显示 / 隐藏主窗口 |
| 托盘右键 | 显示/隐藏，或退出 |

关注列表保存在本机应用数据中，换电脑不会自动同步。

## 常见问题

**双击没反应 / 白屏 / 闪退**  
多半是缺少 WebView2。到官网安装后重试：  
[WebView2 下载说明](https://developer.microsoft.com/microsoft-edge/webview2/) · [引导程序直链](https://go.microsoft.com/fwlink/p/?LinkId=2124703)

**Bangumi 列表加载失败**  
检查网络能否打开 [bgm.tv](https://bgm.tv)。也可改用「手动添加」。

**杀毒软件拦截**  
个人打包、未做代码签名时较常见，添加信任或允许运行即可。

**关不干净**  
窗口 × 只是藏到托盘；请在托盘图标上右键选择退出。
