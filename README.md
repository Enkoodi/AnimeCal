# 番剧日历（AnimeCal）

一款轻量 Windows 桌面悬浮日历，用来盯正在追的番剧更新日期，随时标记已观看。窗口可常驻桌面，支持置顶，一眼看清更新日以及追番清单

## 能做什么

- 日历上有更新的日期显示绿点，并标注当天更新集数
- 点某个日期，查看当天更新的番剧（封面、播出时间、集数）
- 添加番剧：从 Bangumi 搜索或筛当季新番，也可手动填写
- 关注列表保存在本机，换电脑不同步

## 怎么用

1. 双击 `anime-cal.exe` 打开
2. 点右下角 **设置（齿轮）→ 管理番剧**，或点某个日期后选 **添加番剧**
3. 在弹出的窗口里选 **从 Bangumi 添加**，搜索或筛选你想追的番剧，点选（出现 ✓）
4. 关掉管理窗口，回到日历即可看到更新标记

手动添加时请务必填写 **首播日期**（可选填总集数），否则无法正确计算播出区间。

## 数据存在哪

你的追番列表、已看标记和封面缓存都存在 exe 同目录下的隐藏文件夹 `.data` 里，**随 exe 一起携带**，不写入系统。备份或换电脑时，把 `anime-cal.exe` 连同旁边的 `.data` 文件夹一起复制即可迁移所有数据。

## 系统要求

- Windows 10 / 11（64 位），不支持 Windows 7 / 8
- 若打不开或白屏，多为缺少 **Microsoft Edge WebView2**，到官方安装后重试：
  https://developer.microsoft.com/microsoft-edge/webview2/
- 从 Bangumi 添加番剧需能访问 bgm.tv；纯手动添加不依赖外网

## 常见问题

- **双击没反应 / 白屏**：安装 WebView2 后重试
- **被智能筛查拦截**：选「仍要运行 / 更多信息」即可（个人软件未签名常见）
- **关不掉窗口**：右上角 × 只是隐藏到托盘，请在托盘图标右键选 **退出**
- **列表加载失败**：检查网络能否打开 bgm.tv，或改用手动添加
