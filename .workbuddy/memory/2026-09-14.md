## 日历格内数字改为「未看集数优先」

- `src/calendar.js`：新增 `const displayCount = s.unwatched > 0 ? s.unwatched : s.episodes;`，模板里 `${s.episodes}集` → `${displayCount}集`。
- 语义（`getUpdateCountsForMonth` 口径）：`episodes` = 当天总集数，`unwatched` = 当天未看集数。
  - 有未看 → 显示未看集数（同时亮绿点，`showDot = isReached && unwatched > 0` 不变）。
  - 全部看完 → 仍显示当天总集数，并保留 `all-watched` 灰字样式。
- 单位保持「集」未改动。
- 已重新打包，产物中确认存在 `unwatched>0?o.unwatched:o.episodes`。
